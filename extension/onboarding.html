Flash Resume Setup

Welcome to Flash Resume 👋

Tailor your resume for any job posting and download a verified 1-page PDF — without leaving your browser.

  • 🎯ATS keyword injection — high-density keywords from the job description are woven into your existing bullets, never invented.
  • 📄Guaranteed 1-page fit — layout is verified programmatically after compilation.
  • ⚡Seconds, not minutes — local Typst compilation in under 100ms.

Setup takes about a minute. You'll need a terminal window open and a free Gemini API key.

Start the companion engine

The extension talks to a small local server that runs the tailoring pipeline. In your project folder, run:

uv run fs serve

Keep this terminal open while you use the extension. Then check the connection:

Checking…

Add your Gemini API key

Flash Resume uses Gemini Flash for ATS optimization. Grab a free key from Google AI Studio, paste it below, and it will be saved to your local Flash Resume config.

Get a key at aistudio.google.com → Get API key. If you already set GEMINI_API_KEY in your environment, you can skip this step.

You're all set ✅
