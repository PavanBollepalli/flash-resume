Welcome to Flash Resume 👋

Tailor your resume for any job posting and download a verified 1-page PDF — without leaving your browser.

  • 🎯ATS keyword injection — high-density keywords from the job description are woven into your existing bullets, never invented.
  • 📄Guaranteed 1-page fit — layout is verified programmatically after compilation.
  • ⚡Seconds, not minutes — local Typst compilation in under 100ms.

Setup takes about a minute. You'll need a terminal window open and a free API key — Gemini for best quality, or Groq for maximum speed.

Start the companion engine

The extension talks to a small local server that runs the tailoring pipeline. In your project folder, run:

uv run fs serve
